Pattern Laboratory v8.2 for 64-bit Windows 10 and Windows 11 on Intel/AMD computers.

Includes graphical applications for Cayley permutations and restricted growth functions, with a shared native C++ enumeration engine.

Features include:
- Classical, consecutive, and vincular pattern avoidance.
- Enumeration of multiple avoidance classes.
- Statistic distributions, object browsing, and grid diagrams.
- Pattern-containment tools, CSV exports, and optional OEIS lookups.

Version 8.2 fixes an OEIS lookup error that could occur when exactly one matching entry was returned.

To run:
1. Download `PatternLaboratory-v8.2-Windows-x64.zip` under Assets.
2. Extract the complete ZIP and keep its files together.
3. Open `CayleyPatternLaboratory.exe` or `RGFPatternLaboratory.exe`.
4. Click **Run self-test** and check for **Self-test passed.**

No Python, WSL, or compiler installation is required. See the README for examples and further instructions.
